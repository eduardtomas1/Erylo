# Support

Erylo is under active development and is not yet a supported public release.

For reproducible bugs and compatibility problems, [open an issue](https://github.com/eduardtomas1/Erylo/issues/new) with:

- the Erylo revision or version, macOS version, Mac model/chip, and display arrangement;
- the smallest sequence that reproduces the problem;
- whether fullscreen, Spaces, Stage Manager, mirroring, clamshell, hot-plug, sleep/wake, or Reduce Motion is involved;
- expected and observed behavior; and
- redacted diagnostics only when needed.

Before attaching diagnostics, remove usernames, home-directory paths, file names/content, calendar details, media history, tokens, socket payloads, signing information, and other personal data. Do not post vulnerabilities publicly; follow [SECURITY.md](SECURITY.md).

Feature proposals should explain the one-action user outcome, permission and network requirements, idle-energy behavior, failure/cleanup path, and why the feature belongs in Erylo's focused activity surface.
